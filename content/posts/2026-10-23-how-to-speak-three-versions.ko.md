패트릭 윈스턴(Patrick Winston)의 널리 알려진 MIT 강의 [How to Speak](https://ocw.mit.edu/courses/res-tll-005-how-to-speak-january-iap-2018/)의 규칙을 적용해 질량 유량 제어기(MFC) 발표 하나를 3번 작성하였습니다. 규칙으로 발표의 구조를 명확히 하였고, 최종 형태는 청중에 맞춰 결정하였습니다.

## 1. 적용한 규칙

- 약속으로 시작: 발표가 끝나면 청중이 새로 알게 될 내용을 처음에 제시
- 핵심 3회 반복: 어느 시점에든 청중 일부는 집중하지 않고 있음
- 울타리 설정: 아이디어가 무엇이 아닌지 밝혀 비슷한 아이디어와의 혼동 방지
- 구조를 말로 명시: 집중을 놓친 청중이 다시 따라올 수 있음
- 질문 후 대기: 윈스턴은 약 7초를 권장
- 슬라이드는 간결하게: 슬라이드는 보여 주는 용도이며 설명은 발표자가 담당. 글자는 적고 크게 쓰며, 슬라이드를 소리 내어 읽지 않음
- 실제 수행한 일 제시: 아이디어만 제시하지 않음
- 기억에 남는 아이디어: 윈스턴의 ‘별(star)’은 상징, 슬로건, 놀라움, 두드러진 아이디어(salient idea), 이야기의 5개 요소로 구성
- 기여 사항으로 마무리: ‘감사합니다’나 ‘질문 있으십니까?’로 끝내지 않음

## 2. 버전 1: 윈스턴 방식 그대로 적용

첫 번째 버전은 한국어, 슬라이드 11장으로 작성하였습니다. 슬라이드마다 그림 1개와 단어 몇 개만 넣고, 나머지는 모두 발표자가 말로 설명하도록 구성하였습니다.

발표는 다음 3개 부분으로 이어지는 하나의 이야기로 구성하였습니다.

1. 일반적인 MFC 정의와 웨이퍼가 실제로 받는 영향
2. 동일 공급량이 중요한 이유: 적분, 반복, 사용자가 예상과 다른 결과를 겪는 사례, 오버슈트, 환경
3. 결론: 장비사와의 역할 분담, 사양서 추가 항목 4개, 새 정의

이 내용은 [MFC의 역할: 동일 명령에 동일 공급량](/ko/posts/2026-10-23-what-an-mfc-is-for/)으로도 작성하였습니다.

예를 들어 ‘웨이퍼는 무엇을 느끼는가?’ 슬라이드에는 MFC, 배관, 챔버, 웨이퍼를 잇는 상자 4개만 표시하였고, 요점은 발표자의 설명으로 전달하였습니다.

## 3. 버전 2: 윈스턴 구조를 적용한 영어 발표

두 번째 버전은 영어, 슬라이드 23장으로 작성하였으며, 윈스턴의 기법 2가지를 적용하였습니다.

첫째, ‘The way forward(나아갈 방향)’ 슬라이드에 사양서 가설, 웨이퍼 가설, 동일성 가설의 3개 가설을 제시하였습니다. 같은 슬라이드를 끝부분에 다시 배치하여 청중이 전체 흐름을 한 번에 확인하도록 하였습니다.

둘째, 마지막 슬라이드에 기여 사항을 다음과 같이 정리하였습니다.

- 웨이퍼 관점에서도 타당한 MFC 정의
- 사양서 추가 항목 4개
- 항목별 간단한 시험 방법

윈스턴의 별을 적용한 내용은 다음과 같습니다.

<표 1> 윈스턴의 별 적용 내용

| 요소 | 적용 내용 |
|---|---|
| 상징 | 기둥 2개와 보. ‘정확하게’와 ‘빠르게’는 기둥, ‘동일하게’는 보 |
| 슬로건 | 동일 명령, 동일 공급량 |
| 놀라움 | 웨이퍼는 정정 시간이 0.7&nbsp;s인 MFC와 0.3&nbsp;s인 MFC를 구별하지 못함 |
| 두드러진 아이디어 | 동일성 |
| 이야기 | 가설 3개를 발견한 순서대로 제시 |

## 4. 버전 3: 장비사 대상 최종 발표

최종 버전은 한국어, 슬라이드 22장으로 작성하였습니다. 청중이 바뀌어 자사 MFC 채택 여부를 결정할 장비사의 엔지니어가 대상이었으며, 이 청중을 기준으로 앞의 두 버전을 검토한 결과 다음과 같은 문제가 있었습니다.

<표 2> 버전 1·2의 문제와 수정 사항

| 문제 | 수정 사항 |
|---|---|
| 어조가 극적으로 들림 | 국내 기업 보고서 어조로 변경. 짧은 문장, 개조식, 수치 우선 |
| 청중이 어느 MFC가 자신에게 더 적합한지 판단할 수 없음 | 고객이 MFC로 겪는 문제 4가지를 중심으로 재구성 |
| 신호 대 잡음비 개선의 가치가 불명확함 | 고객이 측정하는 값(압력 변화 중 손실되는 공급량)과 단계적으로 연결 |
| 청중이 ‘2&nbsp;%’를 다르게 해석함 | ‘2&nbsp;%’가 의미하는 것과 의미하지 않는 것을 밝히는 울타리 슬라이드 추가 |
| 슬라이드의 글자가 너무 많음 | 슬라이드당 평균 글자 수를 약 207자에서 약 77자로 축소. 나머지는 발표자 노트로 이동 |
| 장비 그림이 없음 | 장비 간이 배치도, 가스 박스 구성도, 공개 특허의 가스 시퀀스 추가 |

고객이 겪는 문제 4가지는 다음과 같습니다.

1. MFC 교체 후 레시피 재조정 필요
2. 같은 스텝이라도 실행마다 과도 응답이 다름
3. 저유량에서 정확도 저하
4. 인접 채널이나 챔버가 가동되면 압력이 변하고, 이에 따라 공급량도 변함

울타리 슬라이드는 반드시 필요하였습니다. 한 그룹은 ‘2&nbsp;%’를 ±2&nbsp;% 정정 범위로 이해하였으나, 의도한 의미는 제어 범위를 일반적인 하한인 풀 스케일의 2&nbsp;% 아래로 확장하는 것이었습니다.

## 5. 최종 버전에 유지한 윈스턴의 규칙

형식은 바뀌었으나, 청중의 주의를 유지하는 윈스턴의 규칙은 다음과 같이 유지하였습니다.

- 약속: 발표가 끝나면 청중이 수치로 설명할 수 있게 될 내용으로 시작
- 반복: 3줄 요약을 시작과 끝에 같은 문장으로 배치
- 울타리: 슬라이드 1장으로 ‘2&nbsp;%’의 의미를 고정
- 실제 수행한 일: 측정 데이터용 슬라이드 1장 확보(측정은 진행 중)
- 질문과 대기: 저유량 그래프 앞에서 ‘풀 스케일의 2&nbsp;%에서 오차는 설정값 대비 얼마나 큽니까?’라고 질문한 뒤 몇 초 대기할 계획
- 어려운 슬라이드 1장: 수식을 담은 슬라이드로 단순한 슬라이드 뒤의 깊이를 제시
- 마지막 슬라이드: 질의응답 중 결론을 화면에 유지

보고서 형식에서는 다음 5개 규칙을 유지하였습니다.

- 슬라이드 제목은 요점을 담은 완전한 문장으로 작성
- 슬라이드 1장에 메시지 1개
- 출처는 슬라이드 하단 각주에 기재
- 세부 내용은 부록에 수록
- 발표자가 말할 내용은 슬라이드가 아닌 발표자 노트에 기재

## 6. 잘못 판단한 점

- 좋은 정의만으로 청중을 설득할 수 있다고 판단함. 고객은 먼저 자신의 문제를 확인할 수 있어야 했음
- ‘2&nbsp;%’가 명확한 표현이라고 판단함. 실제로는 두 그룹이 서로 다른 의미로 이해함
- 초기 슬라이드에 글자를 너무 많이 넣음. 글자를 줄이는 과정에서 발표할 내용을 정확히 정해야 했음

## 7. 요약

- 윈스턴의 규칙(약속, 반복, 울타리, 대기, 기여 사항으로 마무리)은 청중의 주의를 유지하기 위한 것으로, 형식과 관계없이 적용 가능
- 순서와 어조는 청중에 맞춰야 함. 첫 버전은 발표자의 통찰을, 최종 버전은 같은 사실로 고객의 문제를 다룸
- 두 가지로 해석될 수 있는 수치에는 울타리를 설정

이 블로그도 같은 규칙을 따릅니다. 각 글은 핵심 내용을 먼저 제시하고, 요약 목록과 글 끝에서 반복하며, 잘못 판단한 점을 포함합니다.
