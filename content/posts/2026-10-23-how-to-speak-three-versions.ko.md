Patrick Winston의 MIT 강의 [How to Speak](https://ocw.mit.edu/courses/res-tll-005-how-to-speak-january-iap-2018/) 규칙으로 질량유량제어기(MFC) 발표 자료를 세 차례 작성했습니다. 구조는 규칙을 따르고, 최종 형태는 청중에 맞춰 정했습니다.

## 적용한 규칙

- 첫머리 예고: 발표 후 청중이 새로 알게 될 내용을 처음에 제시
- 3회 반복: 요점을 세 번 제시. 청중 일부는 항상 집중하지 않고 있음
- 구분(fence): 혼동하기 쉬운 개념을 들어 내 주장과의 차이를 제시
- 구조 안내: 현재 설명 위치를 말로 안내. 놓친 청중이 다시 따라올 수 있음
- 질문 후 대기: 질문한 뒤 기다림(Winston 권장 약 7초)
- 슬라이드 글자 최소화: 슬라이드는 보여 주는 용도, 설명은 발표자 몫. 글자는 적고 크게, 슬라이드를 소리 내어 읽지 않음
- 실적 제시: 아이디어뿐 아니라 실제로 해 본 결과를 제시
- 기억 장치(star): 상징(symbol), 구호(slogan), 놀라움(surprise), 핵심 개념(salient idea), 이야기(story)
- 기여로 마무리: 마지막 슬라이드에 새로 제시한 내용을 정리. ‘감사합니다’나 ‘질문 있으십니까?’로 끝내지 않음

## 1차안

- 언어와 분량: 한국어, 슬라이드 11장
- 구성: 슬라이드마다 그림 1개와 짧은 문구. 나머지는 말로 설명할 계획
- 예: ‘웨이퍼에 영향을 주는 것은 무엇인가?’ 슬라이드에는 MFC, 배관, 챔버, 웨이퍼를 잇는 상자 4개만 배치

발표 흐름은 다음 세 부분입니다(같은 내용의 글: [웨이퍼 관점에서 다시 정의한 MFC의 역할](/ko/posts/2026-10-23-what-an-mfc-is-for/)).

1. MFC의 일반적인 정의와 웨이퍼에 실제로 영향을 주는 요소
2. 같은 공급량이 중요한 이유: 적분, 반복, 예상과 다른 결과, 오버슈트, 설치 환경
3. 결론: 장비 제조사와의 역할 분담, 사양서 추가 항목 4개, 새 정의

## 2차안

- 언어와 분량: 영어, 슬라이드 23장
- 적용 기법 1: ‘The way forward’ 슬라이드에 가설 3개(사양서 가설, 웨이퍼 가설, 동일성 가설)를 나열하고, 끝부분에서 같은 슬라이드를 다시 제시해 전체 흐름을 보여 줌
- 적용 기법 2: 마지막 슬라이드에 기여 내용을 나열

마지막 슬라이드의 기여 내용은 다음과 같습니다.

- 웨이퍼 관점의 MFC 정의
- 사양서 추가 항목 4개
- 항목별 간이 시험 방법

Winston의 다섯 요소는 다음과 같이 적용했습니다.

| 요소 | 적용 내용 |
|---|---|
| 상징 | 기둥 2개와 보. ‘정확하게’와 ‘빠르게’가 기둥, ‘똑같이’가 보 |
| 구호 | 같은 명령, 같은 공급량 |
| 놀라움 | 정정 시간 0.7초 MFC와 0.3초 MFC는 웨이퍼에서 구분되지 않음 |
| 핵심 개념 | 동일성(매번 같은 공급량) |
| 이야기 | 가설 3개를 확인한 순서대로 전개 |

## 3차안(최종)

- 언어와 분량: 한국어, 슬라이드 22장
- 청중: 우리 회사 MFC의 채택 여부를 결정할 장비 제조사 엔지니어

이 청중을 기준으로 1·2차안을 검토한 결과는 다음과 같습니다.

| 문제점 | 수정 내용 |
|---|---|
| 어조가 극적임 | 회사 보고서 문체(짧은 문장, 개조식, 수치 우선)로 변경 |
| 어느 MFC가 청중에게 유리한지 드러나지 않음 | 고객이 MFC로 겪는 문제 4가지를 중심으로 재구성 |
| 신호 대 잡음비 개선의 효과가 불분명함 | 고객이 측정하는 값(압력 변동 중 덜 공급되는 양)까지 단계별로 연결 |
| ‘2%’를 그룹마다 다르게 이해함 | ‘2%’의 정의와 적용 범위를 밝히는 구분 슬라이드 추가 |
| 슬라이드 글자가 많음 | 슬라이드당 평균 약 207자 → 약 77자, 나머지는 발표자 노트로 이동 |
| 장비 그림이 없음 | 장비 개략 배치도, 가스 박스 구성도, 공개 특허의 가스 시퀀스 추가 |

고객 문제 4가지는 다음과 같습니다.

1. MFC 교체 후 레시피 재조정 필요
2. 같은 스텝에서도 런마다 과도 응답이 다름
3. 저유량에서 정확도 저하
4. 옆 채널이나 챔버가 가동되면 압력이 바뀌고 공급량도 변함

한 그룹은 ‘2%’를 ±2% 정정 허용 범위(settling band)로 이해했습니다. 실제 의미는 통상 하한인 풀스케일 2% 아래까지 제어 범위를 넓힌다는 것이어서 구분 슬라이드를 추가했습니다.

## 최종안에 유지한 Winston 규칙

- 첫머리 예고: 발표 후 청중이 수치로 설명할 수 있게 될 내용을 처음에 제시
- 반복: 세 줄 요약을 처음과 끝에 같은 문장으로 배치
- 구분: 슬라이드 1장으로 ‘2%’의 의미를 확정
- 실적 제시: 측정 데이터 슬라이드 1장 배치(측정은 진행 중)
- 질문 후 대기: 저유량 그래프 앞에서 “풀스케일 2%에서 오차는 설정값 대비 얼마나 될까요?”라고 질문하고 몇 초 대기할 계획
- 어려운 슬라이드 1장: 수식 슬라이드로 다른 슬라이드 수치의 계산 근거 제시
- 마지막 슬라이드: 질의응답 동안 결론을 화면에 유지

회사 보고서 형식에서 가져온 규칙은 다음과 같습니다.

- 슬라이드 제목은 결론을 담은 한 문장(헤드 메시지)
- 슬라이드 1장에 메시지 1개
- 출처는 슬라이드 하단 각주
- 세부 내용은 부록
- 말할 내용은 슬라이드가 아닌 발표자 노트에 작성

## 잘못 판단한 내용

- 좋은 정의만으로 청중을 설득할 수 있다고 판단했음. 고객에게는 자기 문제를 먼저 보여 줘야 했음
- ‘2%’의 의미가 명확하다고 판단했으나, 두 그룹이 서로 다르게 이해했음
- 초기 슬라이드에 글자를 너무 많이 넣었음. 글자를 줄이는 과정에서 말할 내용을 정확히 정해야 했음

## 요약

- 첫머리 예고, 반복, 구분, 질문 후 대기, 기여로 마무리는 발표 형식이 바뀌어도 그대로 적용 가능
- 순서와 어조는 청중에 맞춰 조정. 같은 사실로 1차안은 발표자의 이해 과정을, 최종안은 고객의 문제를 중심에 둠
- 두 가지로 해석될 수 있는 수치는 의미를 별도로 명시
